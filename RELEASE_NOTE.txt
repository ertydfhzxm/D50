版本定位: 以"沉浸式视觉叙事 + 可交互功能体验"为核心的路演展示方案

■ 版本亮点
相比 v1.0 的单页信息展示，v1.5 实现了从"看"到"感受"的跨越。
主页用 7 屏叙事流讲述"为什么做"和"怎么做"，体验页用 3 个可交互 Tab 让评委和路人可以亲手体验核心功能。

--------------------------------------------------------------------------------
一、主页重构：7 屏沉浸式叙事流（index.html）
--------------------------------------------------------------------------------

1. 品牌首屏
   - 内容：Landing-C 品牌名 + Slogan + 赋启青年标识
   - 交互：粒子动效背景、"向下探索"引导

2. 真实声音 (NEW!)
   - 内容：3 张用户痛点卡片（迷茫大四生 / AI 时代绝望 / 家庭压力），引用真实访谈
   - 交互：动态声波波形动画

3. 数据背景
   - 内容：6 组社会数据支撑项目逻辑（含 0% 市场空白点）
   - 交互：数字滚动计数器

4. 产品全景 (NEW!)
   - 内容：5 个手机 Mockup 展示核心模块预览
   - 交互：鼠标悬浮上浮效果 + 亮点标签

5. 五周计划 (NEW!)
   - 内容：5 张可翻转交互卡片，周主题 + 具体行动产出
   - 交互：点击翻转查看背面详情

6. 用户旅程
   - 内容：小林故事线 + SVG 情绪走势图
   - 交互：时间轴节点标注

7. 关于我们
   - 内容：团队愿景 + 联系方式 + 亲自体验入口
   - 交互：跳转至体验页

* 浮动按钮 (NEW!)：右下角"亲自体验"悬浮按钮，滚动显示。

--------------------------------------------------------------------------------
二、二级体验页：功能模拟演示（experience.html）
--------------------------------------------------------------------------------

独立的演示页面，供评委/路人亲手体验功能。

Tab 1：AI 情绪伙伴
- 交互：3 轮 × 3 选项的选择式对话模式。
- 人设：不仅是 AI，更是有过待业经历的同路人。
- 细节：带模拟"打字中…"动画，增强真实感。

Tab 2：情绪日记
- 流程：选心情 -> 写文字 -> 提交记录。
- 反馈：显示温柔鼓励文案 + 本周日记统计 + 迷你趋势柱状图。

Tab 3：叙 narrative 会馆 (叙事馆)
- 交互："共情"按钮（🤝）替代传统"点赞"。
- 内容：4 篇涵盖求职、Gap、家庭压力的匿名真实故事。
- 反馈：点击共情弹出随机温暖文案（"我懂你" / "你很棒"）。

--------------------------------------------------------------------------------
三、关键技术与视觉升级
--------------------------------------------------------------------------------

- 纯代码图形：声波、手机 Mockup、翻转动画、粒子系统均由 CSS/SVG/Canvas 实现，零图片依赖。
- 极致性能：纯原生 HTML/CSS/JS 编写，秒拉加载，离线完美运行。
- 排版修复：针对 Landing-C 品牌名中 'g' 字母裁断问题进行了 CSS 专项优化。

--------------------------------------------------------------------------------
四、路演演示攻略 (建议总时长 3-5 分钟)
--------------------------------------------------------------------------------

1. [开始] 开启全屏 (F11)，停留首屏展示品牌和 Slogan (30s)
2. [痛点] 滚动到"真实声音"，朗读一段用户心声 (30s)
3. [数据] 展示"数据背景"，强调 0% 市场空白点 (20s)
4. [产品] 通过"产品全景"和"五周计划"展示专业深度 (50s)
5. [交互] 点击右下角"亲自体验"，现场操作 AI 对话或记日记 (60s)
6. [结束] 点击"返回主页"完成闭环。
